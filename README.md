# React + Strapi Blog

A modern blog application built with React, TypeScript, Vite, and Strapi CMS.

## Tech Stack

### Frontend

- React
- TypeScript
- Vite
- Tailwind CSS
- Axios

### Backend

- Strapi CMS
- SQLite

---

## Project Structure

```txt
frontend → React
backend → Strapi
```

Getting Started:

-Frontend

```txt
cd frontend
npm install
npm run dev
```

-Backend

```txt
cd backend
npm install
npm run develop
```
